## 图像与来源边界

当前交付默认使用 `pregenerated`，服务端拒绝 `ai_reference`；生成、重生成、选图、切换平台和导出均不调用生图 API。历史 `layout`/AI 生图说明不代表当前模式。文案仍按实际配置调用模型，不因固定图片改用模拟文案。

本轮 12 张用户素材已放入 `ui/assets/pregenerated/`，清单为 `manifest.json`，由 `/assets/pregenerated/...` 静态 URL 提供。公众号、朋友圈各 3 张；小红书 6 张中，前 3 张可按 X Pro 系列范围选择，2 张型号未确认而隔离，1 张明确 MateBook 14，不能混入 X Pro。系列匹配不等于完整型号、配置或视觉已核验。每个平台独立保存所选图片、顺序和文案草稿；原图不重复叠字，单图下载和 ZIP 使用真实选中的原文件及顺序。

素材 `source_type=pre_generated`，授权 `unconfirmed`，视觉核查 `unknown`。人工登记图中文字不等于 OCR 或完整视觉检查，不授予虚构的 evidence ID。无匹配素材、数量不足或加载失败时如实提示，不跨型号补图。换图、改顺序或改文字会失效旧最终核查，图片未知不能显示“可直接发布”。操作与维护见 [素材说明](../ui/assets/pregenerated/README.md)。

local 资料 `live=false`；检索时间不代表发布时间或当前有效性；来源类型 other 不升级为官方。场景、时间、手填门店来自用户需求，不推断客流或购买意愿。A supported 只表示本次来源支持当前陈述，B 本地 lint 不替代 A 全文事实核查。
